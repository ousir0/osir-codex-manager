# 中文 / English 语言切换说明

本文说明 Codex Manager、官网和 GitHub 文档分别如何切换语言。

## Codex Manager 桌面端

1. 打开 Codex Manager；
2. 进入“设置”；
3. 打开“外观”；
4. 找到“语言”；
5. 选择“中文”或“English”。

切换后，导航、按钮、状态提示、安装流程和设置页面会使用新的语言。

如果部分系统菜单仍使用旧语言，请完全退出 Manager 后重新打开。

## Codex Manager 官网

1. 打开 Codex Manager 官网；
2. 点击导航栏右侧的语言按钮；
3. 在中文和 English 之间切换。

官网语言选择会保存在当前浏览器中。清除网站数据后，需要重新选择。

## GitHub README

README 顶部提供中文和 English 入口：

- 中文：阅读 README 的“中文”部分；
- English：点击顶部的 English 锚点，或直接阅读后半部分。

README 适合快速了解项目、下载和开发；完整用户操作请阅读用户手册。

## 完整用户手册

- 中文：docs/user-guide-zh-CN.md
- English：docs/user-guide-en.md

两份手册的章节顺序保持一致，方便中英文对照。

## OSIR API 网站

OSIR API 网站也提供独立的语言切换入口。Manager 官网和 OSIR API 网站是两个产品入口：

- Codex Manager：安装、更新、配置和主题；
- OSIR API：API Key、模型、控制台、价格和 API 文档。

切换 OSIR API 网站语言不会改变 Manager 桌面端语言。
