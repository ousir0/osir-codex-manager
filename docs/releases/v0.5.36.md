# Codex Manager v0.5.36

## 重点更新

- 修复 Manager 更新或 OpenCodex 模型同步后，Codex 选择器仍读取旧 models_cache.json 的问题。
- 模型同步现在按“生成目录、清理过期模型、刷新 Codex 缓存”的顺序完成，已下线的 Gemini 等模型不会继续残留在选择器中。
- Manager 自更新后的首次恢复会刷新缓存并重启仍持有旧模型列表的 Codex app-server；普通同步仍保留重启提示，避免打断正在进行的任务。
- 缓存刷新失败时自动恢复同步前配置，避免 OpenCodex 目录、Codex 配置和模型缓存不一致。

## 用户侧验收

从 v0.5.35 点击“立即更新”。更新完成并重新打开 Manager 后，Codex 的模型选择器应只显示当前 OpenCodex 目录中的模型；gemini-2.0-flash 等已移除模型不再出现，GPT、Claude、Gemini 和 Grok 按稳定顺序展示。
