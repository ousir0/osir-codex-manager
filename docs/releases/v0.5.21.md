# Codex Manager v0.5.21

## Highlights

- Adds explicit, confirmed activation for Default configuration and OpenCodex multi-model mode. Selecting a mode only opens its workspace; it never changes the active Codex gateway by itself.
- Restores the pre-OpenCodex `config.toml` snapshot when returning to Default configuration.
- Adds a one-click path to activate previously saved OpenCodex routes.
- Shows provider connection/model check states and an explicit Codex restart action when a running Codex process needs to reload configuration.
- Keeps conversation databases in the shared Codex home; gateway switching only changes routing configuration and does not move or delete history.
