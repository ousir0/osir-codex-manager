# Codex Manager v0.5.40

## 修复内容

- 修复更新后已存在的 OpenCodex 组件被误判为未安装的问题。兼容 macOS 组件中以 `bun.exe` 文件名保存的原生 Bun 运行时，避免重复安装时报更新失败。
- OpenCodex 同步、启用和 Manager 更新重载前，会从已配置供应商的 `/models` 合并新模型，避免模型白名单停留在旧版本。
- 默认配置模式会刷新 Codex 原生 `models_cache.json`。API 登录且上游已开放的 `gpt-6-astra` 会进入选择器，显示为 `GPT 6 Astra`。
- 模型缓存刷新失败时保留现有本地配置，不阻塞管理器打开；Codex 正在运行时会标记需要重启，以确保选择器读取新缓存。
