# Codex Manager v0.5.10

## 本次更新 · This release

修复首次安装 OpenCodex 后无法完成模型同步的问题，并改善 Windows 用户体验。

Fixes first-run OpenCodex synchronization after installation and improves the Windows user experience.

## 修复 · Fixes

- **首次安装与同步**：Manager 现在为 OpenCodex 统一配置用户目录，服务启动后确认 ready，再执行模型同步；遇到旧进程导致的本机管理接口 404 时会自动恢复并重试。
  **First-run install and sync**: Manager now uses one OpenCodex home, waits for readiness before syncing, and recovers once from a stale local management process returning 404.
- **Windows 弹窗**：Node、npm 和 OpenCodex 后台命令使用无窗口模式，保留输出用于错误诊断。
  **Windows console popups**: background Node, npm, and OpenCodex commands now run without console windows while retaining diagnostics.
- **版本契约**：客户端组件与 OSIRAPI 接入协议统一使用 OpenCodex 2.22.0。
  **Version contract**: the bundled component and OSIRAPI integration contract now use OpenCodex 2.22.0 consistently.

## 验证 · Verification

- macOS clean-component smoke: passed with OpenCodex 2.22.0.
- Frontend tests: 345 passed.
- Rust library tests: 192 passed.
- Windows installer and clean-user lifecycle: verified by the Windows 2022 CI runner before publication.
