# Codex Manager v0.5.6

## 亮点 · Highlights

- **Manager 自动更新**：启动或定时检查到新版本后，任意页面都会显示更新确认弹窗；用户可稍后提醒、跳过当前版本或立即更新。
  **Manager self-update**: startup and periodic checks now surface a global update dialog with defer, skip-version, and install actions.
- **OpenCodex 多模型安装闭环**：自动识别已有环境，缺少 Node/npm 时使用 Manager 私有运行时，并在安装、启动、授权和路由验证后才报告成功。
  **OpenCodex setup**: existing runtimes are reused, missing runtimes are prepared privately, and success requires service, account, model, and route verification.
- **Windows x64 干净环境验收**：GitHub Actions 会在隔离用户目录中执行安装、首次启动、升级和卸载，并上传测试安装包。
  **Windows x64 clean-room smoke**: GitHub Actions validates install, first launch, upgrade, and uninstall in isolated user data and uploads the test installer.

## 修复 · Fixes

- 修复 Manager 更新只在“关于”页手动检查、启动时不会自动提醒的问题。
  Fixed the gap where Manager updates were only discovered manually from About.
- 修复版本发布后缺少重启确认的问题；更新前记录目标版本，重启后重新确认版本已切换。
  Added post-restart confirmation for the requested Manager version.

## 核验与已知限制 · Verification and known limitations

- 本地前端测试、Rust 测试、类型检查和 Lint 必须全部通过。
- Windows x64 安装包会由 GitHub Actions 在真实 Windows runner 上执行干净环境验收。
- 当前预览构建可能没有 Windows Authenticode 或 macOS 公证；发布说明以 CI 实际结果为准。
- 更新信任由 Tauri updater 公钥和签名清单提供，不等同于系统发行者签名。
