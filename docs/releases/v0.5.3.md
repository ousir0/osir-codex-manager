# AWAI Codex App Manager v0.5.3

本版本完善 Windows 中文启动、Codex 配置与独立生图链路，并修复重复重启和技能升级问题。

## 亮点 · Highlights

- **独立生图配置**：聊天供应商与生图供应商可分别设置 Base URL、API Key 和模型；生图模型通过独立按钮获取。
  Image generation now has an independent Base URL, API key, model selector, and model discovery action.
- **多图编辑**：兼容 OpenAI 风格 `/images/edits` multipart 请求；多张参考图按顺序重复提交 `image[]`。
  Multi-image edits preserve reference order and upload repeated `image[]` multipart fields.
- **零 Python Windows 助手**：Windows 使用隐藏 PowerShell 和系统 `curl.exe`，支持常见 Base64 与 URL 图片响应并校验真实文件格式。
  Windows uses hidden PowerShell plus the system curl, accepts common Base64 and URL responses, and verifies the resulting image format.
- **中文启动链路**：Manager 启动 Codex 时显式设置 `zh-CN`，并仅将 `ab.chatgpt.com` 本地化云控请求分流到受限 AWAI 中继。
  Manager launches Codex with `zh-CN` and routes only the localization control host through the restricted AWAI relay.

## 修复 · Fixes

- 已运行的 Codex 显示“重启”，并使用单次重启流程，避免重复启动后客户端再次退出。
- 保存供应商后可在 Codex 运行期间继续修改；界面明确提示重启后生效。
- 重装或升级 Manager 后，打开 Codex 配置页面会自动刷新已配置的内置生图技能，无需重新填写 API Key。
- Gitee 皮肤回退地址修正为 AWAI 皮肤仓库的 `main` 分支。

## 核验与已知限制 · Verification and known limitations

- Windows x64 已通过本地 NSIS 构建、PowerShell 5.1 语法检查、Base64/URL 生图响应端到端测试及项目测试。
- Windows 安装器当前没有 Authenticode 签名，SmartScreen 可能提示未知发布者；请核对 Release 中的 SHA-256。
- 本次不推进 Tauri 自动更新清单：现有 updater 私钥未配置到新仓库，官网与 GitHub 手动下载不受影响。
