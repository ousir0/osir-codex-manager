# Codex Manager v0.5.9

## 本次更新

- DreamSkin 社区主题库接入 393 套主题，官网和 Manager 均支持浏览、详情查看和一键安装。
- 主题下载按版权状态分流：可公开镜像的包走雨云对象存储，其他主题从 DreamSkin 官方来源下载；安装前校验 SHA-256。
- 主题预览改为 CodeX 完整界面效果：包含侧栏、项目列表、欢迎区、快捷卡片、对话区、输入框、背景焦点、圆角、模糊、边框和阴影。
- 详情支持“欢迎页 / 对话页”场景切换，并展示作者、许可证、来源、包大小、SHA-256、色板和版权说明。
- 官网支持通过 osircodex://skin/install?id=... 安全唤起 Manager 安装并应用主题。
- DreamSkin v1 主题包可自动转换为 Manager v2 格式，兼容驼峰颜色键。

## 用户影响

- 已安装用户会通过 Manager 自更新收到本版本提示。
- 用户数据、Codex 会话、OpenCodex 配置和模型目录不会被删除或重置。
- 主题大文件不经过模型调用服务器，降低带宽占用。
- DreamSkin 主题的使用和再分发范围以原作者许可证为准；如有权利问题可联系下架。

## 已知限制

- macOS/Windows 是否显示系统级签名提示，取决于当前发布工件的签名配置。
- 官网点击“在 Manager 中安装”需要本机已安装并注册 v0.5.9 或兼容版本的 Manager。
