# AWAI Codex App Manager v0.5.12

## 修复 · Fixes

- **OSIRAPI 授权路由**：修复授权后 OpenCodex 将有效网关 Key 按错误认证模式验证的问题。现在会明确使用 API Key + Bearer 认证，授权后可直接完成默认 GPT 路由验证。
  **OSIRAPI authorization routes**: valid gateway keys are now explicitly configured as API-key/Bearer routes so the default GPT verification succeeds after OAuth.
- **订阅 Key**：云端授权会为 GPT、Claude、Grok 保持三把独立 Key，并按对应订阅分组绑定。
  **Subscription keys**: the cloud flow keeps three distinct keys for GPT, Claude, and Grok, each bound to its matching subscription group.

## 更新方式 · Update

已安装 Manager 的用户会在客户端弹出更新提示。点击“更新”后，Manager 会下载、校验、安装并自动重启；不需要重新下载安装包。

Installed users receive an in-app update prompt. Clicking “Update” downloads, verifies, installs, and relaunches the Manager without a manual reinstall.
