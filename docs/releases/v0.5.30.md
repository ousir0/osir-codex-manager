# Codex Manager v0.5.30

## 重点更新

- 修复 OSIRAPI 订阅授权只显示 GPT、Claude、Grok 的问题。
- 支持 Gemini 订阅路由和 osirapi-gemini Provider。
- 授权后的 Provider、Key 和模型目录按当前订阅套餐实际包含的 active 分组动态同步。
- 套餐减少平台时，重新授权会清理本次不再支持的订阅路由；套餐增加平台时，会同步新增路由和模型。
- 更新内置 OSIRAPI Codex 安装器，支持动态 Provider 数量。

## 使用方式

打开旧版 Manager，点击更新提示中的“立即更新”。更新完成并重启后，退出 OSIRAPI 连接，再重新授权即可读取最新订阅平台和模型。

## 已知限制

服务端必须同步部署动态订阅分组版本；仅更新 Manager 客户端不会让旧服务端返回 Gemini。
