# Codex Manager v0.5.44

## 修复内容

- 修复多模型配置弹窗输入时焦点被重复抢占，连续填写供应商信息可以正常完成。
- 修复退出 OSIRAPI 后没有明确重新登录入口的问题；退出后保留本地路由，重新登录可恢复订阅状态。
- 修复手动保存时重复提交已有 OAuth 路由、重复同步和覆盖其他供应商配置的问题。
- 修复保存、锁定路由、移除模型失败时配置文件与运行中服务可能不一致的问题，失败自动恢复。
- 修复移除模型后 OpenCodex 的 provider 模型列表未同步的问题。
- 修复浏览器预览状态、模型路由选择和异步刷新之间的状态覆盖问题。
