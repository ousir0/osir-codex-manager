# Codex Manager v0.5.5

本版本重点完善 Codex 多模型工作台与全屏配置体验。

## 主要变化

- 全屏工作台默认尺寸调整为更适合配置管理的桌面比例。
- Codex 配置管理在全屏模式下改为左侧模块导航与右侧工作区。
- 多模型连接入口改为弹窗式配置，减少页面跳转和滚动。
- 支持从模型列表移除单个 OpenCodex 模型，并同步模型目录。
- 支持直接打开 OpenCodex 本地控制台。
- 自动接管已有 OpenCodex 配置，补齐 Codex Provider 和模型目录配置。
- 修复新会话创建时 Model provider opencodex not found 的配置问题。

## 验证

- 前端测试 335/335 通过。
- OpenCodex Rust 专项测试 5/5 通过。
- 窗口模式测试通过。
- macOS arm64 构建通过。
- Windows、macOS 和审计门禁通过后发布。

## 已知限制

- macOS 正式无警告发布仍需要 Developer ID 与公证凭据。
- 移除模型后需要完全重启 Codex，模型选择器才会刷新。
