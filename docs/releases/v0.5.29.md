# Codex Manager v0.5.29

- 修复在 OpenCodex 多模型与默认配置之间切换后，历史会话被隐藏、无法继续对话的问题。
- 切换时事务性迁移 Codex 会话索引中的供应商和模型标识；会话正文文件保持原位，不删除、不重写。
- 为会话索引生成切换前备份，切换失败自动恢复配置、状态和备份文件。
- 已处于默认模式的旧版本用户，打开配置管理时会自动修复遗留的 OpenCodex 路由标识。
- 切回默认配置前使用真实 `/responses` 请求验证模型；鉴权失败会阻止切换并保留当前可用配置，临时网关错误自动重试。

升级后如 Codex 当时正在运行，请按提示重启 Codex，使原生模型选择器重新读取配置。
