# Codex Manager v0.5.37

## 重点更新

- 恢复 Codex 原生模型选择器的宽度、字体、背景、圆角和交互观感。
- 修复模型列表被过度挤压、文字重叠和模型行高度不稳定的问题。
- 模型选择器按模型数量自适应高度，最高不超过 Codex 界面约三分之二，超出后内部滚动。
- 模型供应商标识统一显示为小写 osir，不改变内部模型路由 ID。
- 保留 OpenCodex 模型同步、旧会话迁移和推理能力适配逻辑。

## 用户侧升级

本版本需要通过 Codex Manager 的“检查更新 / 立即更新”安装。发布后，旧版 Manager 会从正式更新地址检测到 0.5.37，用户确认后自动下载、校验、安装并重启。
