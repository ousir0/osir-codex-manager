# Codex Manager v0.5.48

- Manager 管理的 OpenCodex 2.22.0 在模型请求失败时保留选中的策略路由，原样返回错误，不再自动尝试策略中的备用 API 或模型。同一 API 的其他模型仍可手动选择使用。
- 更新后的自动重载会为已安装组件应用路由修复；新安装、私有 npm 安装和服务重启也执行相同检查。CodeX 正在运行时暂缓重载，退出后自动处理；无需重新授权或手工编辑配置。
- 修复缺少时间字段的旧会话数据库在升级修复时出现的排序错误。

## 说明

此版本修复的是请求失败后的自动回退行为，不能消除上游自身的 502、超时或模型容量不足。
对不兼容的第三方 OpenCodex 版本不强行替换文件；修复失败会保留待处理状态。
Windows 安装包可能没有 Authenticode 签名，首次运行可能出现 SmartScreen 提示；Manager 自更新仍使用 Tauri 更新签名校验。
