# Codex Manager v0.5.41

## 修复内容

- 修复已启动的 OpenCodex 在 Codex 默认供应商仍占用配置时同步目录失败的问题。启用流程现在会先转移 Codex 接管权，再启动服务、同步目录并完成验证。
- 启用失败会恢复接管前的 Codex 配置、OpenCodex 配置、模型目录和缓存，不留下半完成状态。
- 修复父页面已经启用多模型后，子面板仍显示“启动”按钮的问题；服务就绪后显示已启用状态。
- 保留启用失败的具体错误，避免焦点刷新或普通状态检测覆盖错误提示。
- Manager 更新后，Codex 正在运行时暂缓自动重载，保留待同步状态，避免重启代理导致会话中断。
- 移除模型缓存同步中的强制重启 Codex；用户退出 Codex 后再由 Manager 完成重载，或在用户主动重启时、重新启动进程前完成重载。
