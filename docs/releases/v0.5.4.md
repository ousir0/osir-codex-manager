# Codex Manager v0.5.4

本版本将 OpenCodex 多模型能力正式接入 Codex Manager，并保持 OpenCodex 组件独立下载，不增加 Manager 安装包体积。

## 主要能力

- CODEX 配置管理新增多模型工作台。
- 支持从 Manager 外置下载并校验 OpenCodex 组件。
- 支持 OSIRAPI 一次性连接码和加密配置包。
- 支持 GPT、Claude、Grok 多路由配置和模型同步。
- 支持路由可用性验证、状态持久化和锁定默认路由。
- OpenCodex 服务或模型目录不可用时，阻止 Codex 启动，避免进入空白模型选择器。
- 支持 OpenAI Compatible 自定义供应商路由。

## 组件来源

- OpenCodex：`@bitkyc08/opencodex@2.22.0`。
- Node.js：`22.19.0` 外置运行时。
- 组件下载优先使用 `https://app.osirclaw.com/components/opencodex`，GitHub Release 作为备用。
- Manager 安装组件前校验 SHA-256；组件包不嵌入 Manager 安装器。

## 验收

- 前端测试、Rust 测试、Clippy、cargo audit 和 cargo deny 通过。
- Windows x64 安装、启动、升级、卸载 smoke test 通过。
- Windows ARM64 构建、PE 架构和 updater 签名通过。
- macOS Rust 与 packaged smoke 验收通过。
- 干净临时 HOME、无 Node/npm PATH 环境下，外置组件下载、校验、解压、启动和配置校验通过。

## 已知限制

- Windows ARM64 OpenCodex 组件仍需要真实 ARM64 Windows 设备做最终运行验收；云端已完成 ARM64 组件打包和 Manager PE 构建验证。
- macOS 正式无警告发布仍需要 Developer ID 和公证凭据。
