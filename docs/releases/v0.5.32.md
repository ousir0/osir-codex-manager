# Codex Manager v0.5.32

## 重点更新

- 修复 Manager 点击“立即更新”后，后台 OpenCodex 进程仍持有旧供应商路由的问题。
- 更新前记录一次性重载标记；新版 Manager 启动时自动重启 OpenCodex、同步真实模型目录并校验所有已启用供应商模型。
- 不再把未被 OpenCodex 实际暴露的模型伪装成可用模型，避免模型选择器可见但请求返回 404。
- OSIRAPI 授权完成时逐条验证订阅返回的供应商推荐模型，失败会显示具体供应商和模型。

## 用户侧验收

旧版 Manager 打开更新检查，点击“立即更新”。更新完成并重启后，无需重新授权；新版会自动重载已保存的 OpenCodex 订阅路由。进入 Codex 配置页确认模型列表后，分别用订阅中包含的 GPT、Claude、Gemini、Grok 等供应商模型发送一次请求。

## 已知限制

如果新版 Manager 启动时 OpenCodex 重载遇到网络或服务异常，重载标记会保留，管理器会在下一次读取状态或启动 Codex 时继续重试，并显示具体错误。
