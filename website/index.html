OUR DIFFERENCE

三个真正有用的不同。

01

安装与更新

按系统和架构选择安装包，下载后校验，更新失败时保留原版本。

02

配置与多模型

普通 API、生图 API 和 OpenCodex 路由分开管理，缺少运行环境时自动准备。

03

主题与恢复

预览、试用和恢复主题，不修改 Codex 应用文件；配置和更新都有备份。
