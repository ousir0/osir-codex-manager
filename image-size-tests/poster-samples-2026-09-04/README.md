# GPT Image 2 海报样图测试

## 目标

使用 `img.yunfei.best` 的 `gpt-image-2` 编辑接口，参考既有 OSIR API 海报，生成三套可直接比较的竖版海报样图。

## 样图方向

1. 科技速度版：蓝黑霓虹、线路拓扑、多模型接入。
2. 企业稳定版：银灰机房、稳定调度、状态可见。
3. 瑞士数据版：深蓝网格、编辑排版、信息清晰。

## 验收重点

- 主标题是否清楚。
- 中文是否可读。
- 构图裁成 3:4 后是否完整。
- 返回图片的真实像素尺寸。
- 参考风格是否稳定保留。

## 实测结果

| 样图 | 实际返回尺寸 | 结果 |
|---|---:|---|
| 科技速度版 | 1024×1536 | 成功，中文和二维码留白完整 |
| 企业稳定版 | 1024×1536 | 首次 504 超时，15 秒后重试成功 |
| 瑞士数据版 | 1024×1536 | 成功，网格与信息层级清楚 |

结论：编辑接口能够直接返回标准竖版 `1024×1536`，不需要把方图二次裁切。三张样图均保持了参考海报的主要视觉语言。
